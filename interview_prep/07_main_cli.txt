QUESTION 1: CLI VS WEB UI IN ARCHITECTURE
Q: "Why have both a CLI (`main.py`) and a Web UI (`app.py`)?"

Interviewer is testing: Software engineering fundamentals, automation, and
   testability.

IDEAL ANSWER:
"1. Headless Automation & CI/CD: A CLI runner allows the entire meeting
   intelligence pipeline to be invoked via shell scripts, cron jobs, or
   automated Docker pipelines without spinning up browser rendering overhead.
2. Developer Productivity & Rapid Debugging: Testing prompt changes or vector
   retrieval via CLI takes seconds, bypassing UI state refreshes.
3. Separation of Concerns: `main.py` and `app.py` both act as thin
   presentation consumers over the modular `core/` business logic."


--------------------------------------------------------------------------------
QUESTION 2: PIPELINE ORCHESTRATION & STATE MANAGEMENT
Q: "How does `run_pipeline()` manage data transfer between stages?"

Interviewer is testing: Functional design and intermediate representation.

IDEAL ANSWER:
"It implements a sequential data pipeline pattern:
Input (source string)
  ──► Chunks (List[str] file paths)
  ──► Transcript (clean text string)
  ──► Intelligence outputs (Title, Summary, Action Items, Decisions, Questions)
  ──► RAG Runnable Chain (LCEL object)
All results are bundled into an immutable dictionary payload. This dictionary
acts as the single source of truth passed to the downstream consumer."


--------------------------------------------------------------------------------
QUESTION 3: PRODUCTION DEPLOYMENT & CONTAINERIZATION
Q: "How would you package this application for deployment on cloud servers
   (AWS/GCP)?"

Interviewer is testing: DevOps, Docker, and environment isolation.

IDEAL ANSWER:
"1. Multi-Stage Dockerfile:
   - Base image: `python:3.10-slim`.
   - Install system dependencies:
     `apt-get update && apt-get install -y ffmpeg`.
   - Install Python dependencies from `Requirements.txt`.
2. Hardware Acceleration: If running Whisper locally on GPU, use an NVIDIA
   CUDA base image (`nvidia/cuda:12.1-runtime-ubuntu22.04`) with PyTorch GPU
   wheels.
3. Secrets Management: Never bake API keys into images; inject `MISTRAL_API_KEY`
   and `SARVAM_API_KEY` at runtime via AWS Secrets Manager or Kubernetes
   Secrets."
